## 2. Integrated Gradients Metadata & Algorithm Reconciliation

### 2.1 Backend Audit & Discrepancy Resolution
- **Backend Audit:** The underlying PyTorch implementation in `ml/ecg_classification/explainability/integrated_gradients.py` implements straight-line path integrals with configurable quadrature methods: `riemann_middle` (default Riemann sum approximation with uniform steps), `trapezoid` rule, and `gauss-legendre` quadrature. In the production orchestrator (`backend/app/services/ecg/explainability_service.py`), `ECGIntegratedGradients.attribute` is invoked with `n_steps=50` (or the client's requested steps) along a zero baseline in standardized tensor space (`zero_standardized_space`).
- **Discrepancy Resolution:** Phase 8.4 documentation briefly referenced Gauss-Legendre quadrature; however, the actual API contract returns:
  - `method: "INTEGRATED_GRADIENTS"`
  - `baseline: "zero_standardized_space"`
  - `integration_steps: int` (default 50)
  - `completeness_error: float` (e.g., 0.0034)
- **Frontend Correction:** The frontend component `IntegratedGradientsAttributionPanel` was verified to dynamically render the exact strings returned by `attribution.method`, `attribution.baseline`, and `attribution.integration_steps` from the backend response rather than hardcoded descriptions.

## 3. ECG Image Overlay Geometry & Aspect Ratio Verification

### 3.1 Dimension Reference System
In `EcgLeadAlignment.jsx` (`LeadOverlayMap`), bounding box coordinates are received from the backend as absolute pixel coordinates (`x_min`, `y_min`, `x_max`, `y_max`, `width`, `height`) defined in the coordinate system of the raw scan.
- **Dynamic Natural Dimension Tracking:** Added dynamic image loading listener:
  ```jsx
  onLoad={(e) => {
    if (e.target.naturalWidth && e.target.naturalHeight) {
      setNaturalDims({ w: e.target.naturalWidth, h: e.target.naturalHeight });
    }
  }}
  ```
- **Percentage Coordinate Conversion:** Coordinates are converted to percentages against `naturalDims.w` and `naturalDims.h`:
  ```javascript
  leftPct = (box.x_min / naturalDims.w) * 100;
  topPct = (box.y_min / naturalDims.h) * 100;
  widthPct = (box.width / naturalDims.w) * 100;
  heightPct = (box.height / naturalDims.h) * 100;
  ```
- **Coordinate Reference Consistency:** Because the overlay container wraps the responsive `<img>` tag directly (`relative max-w-full overflow-hidden`), the image and its overlays share the exact same aspect ratio and bounding box without stretching, letterboxing drift, or overlay misalignment during browser resizing or zoom.
- **Separation of Lead II Quadrant vs Continuous Rhythm Strip:** Lead II in row 1 (2.5s quadrant) and row 3 (full 10.0s rhythm strip) are kept strictly separate:
  - Lead II quadrant: `width: 400px` (`~24.0%` of canvas), `is_rhythm_strip: false`.
  - Lead II rhythm strip: `width: 1550px` (`~93.1%` of canvas), `is_rhythm_strip: true`, labeled `Lead II (Continuous Rhythm)`.

## 4. Clinical Measurements Correctness & Calibration Gating

In `EcgClinicalMeasurements.jsx`:
- **Direct Backend Propagation:** HR, RR, PR, QRS, QT/QTc, and ST deviation propagate directly from `clinical_measurements` generated by `ECGMeasurementEngine` and `ECGWaveformDelineator`. No measurement calculations or heuristic estimators exist in React.
- **Status Distinction:**
  - `VALID`: Only displayed when `is_calibrated === true` (verified 25 mm/s and 10 mm/mV pulses).
  - `UNRELIABLE (UNCALIBRATED)`: Displayed whenever `is_calibrated === false`.
  - `UNAVAILABLE`: Displayed when an interval or metric is `null` or `undefined` (never replaced with artificial defaults like 0 ms).
- **Physical Unit Gating:** ST segment deviation displays `mV` only when calibrated, and falls back to `px` (pixel units) with a prominent amber alert banner explaining that physical caliper verification is required.

## 7. Security and Browser Behavior Audit

- **Authentication Interceptors:** All image blob requests and explainability calls utilize the existing Axios instance with `Authorization: Bearer <token>` interceptors. Direct image streaming URLs are never embedded as bare public tags.
- **Memory Hygiene:** Object URLs created via `URL.createObjectURL(blob)` are immediately released via `URL.revokeObjectURL(url)` whenever a user selects another record or the component unmounts.
- **State Isolation:** Changing the active patient immediately clears previous ECG history, loaded scan images, and active explainability data, preventing cross-patient data bleeding.
- **No Local Storage Leakage:** Patient waveforms, explainability tensors, and diagnostic predictions are held purely in memory and are not stored in `localStorage` or `sessionStorage`.
